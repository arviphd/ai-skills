# Claude skills

Skills for Claude (claude.ai, the Claude desktop app, and Claude Code).

Each skill is a directory named after the skill, containing a `SKILL.md`
with `name` and `description` frontmatter plus any supporting files.

To install one in Claude Code, copy its directory into `~/.claude/skills/`
(user-level) or `<repo>/.claude/skills/` (project-level). For claude.ai or the
desktop app, zip the skill directory and upload it under Settings → Skills.
